# LAMS Clima — Frontend

Frontend για τη μαθησιακή δραστηριότητα **LAMS Clima**. Περιλαμβάνει τη
διαδραστική προσομοίωση κλιματικής αλλαγής στην Ελλάδα (`clima.php`) που
βλέπουν οι μαθητές, καθώς και τον πίνακα ελέγχου του εκπαιδευτικού
(`monitor.php`) για την παρακολούθηση της προόδου των φοιτητών.

## Επισκόπηση

Το frontend αποτελείται από δύο σελίδες PHP:

1. **`clima.php`** — Η κύρια δραστηριότητα. Ο φοιτητής επιλέγει ένα κλιματικό
   σενάριο και ένα έτος πρόβλεψης, εκτελεί την προσομοίωση και βλέπει
   διαγραμματικά την εξέλιξη της θερμοκρασίας και της υγρασίας. Η πρόοδος
   αποστέλλεται αυτόματα στη βάση δεδομένων.
2. **`monitor.php`** — Ο πίνακας ελέγχου του εκπαιδευτικού. Εμφανίζει
   στατιστικά και τη λίστα των φοιτητών με την πρόοδό τους, με αυτόματη
   ανανέωση κάθε 5 δευτερόλεπτα.

## Δομή του Έργου

```
frontend/
├── clima.php    # Διαδραστική προσομοίωση κλιματικής αλλαγής (για μαθητές)
└── monitor.php  # Πίνακας ελέγχου εκπαιδευτικού (στατιστικά & πρόοδος φοιτητών)
```

## Απαιτήσεις

- PHP 8.1+ (με επέκταση PDO MySQL)
- MySQL / MariaDB
- Ένας web server (Apache, Nginx κ.λπ.)
- Το backend του έργου (για τη σύνδεση με τη βάση δεδομένων και την
  αποθήκευση βαθμών)

## Εγκατάσταση

1. Τοποθετήστε τα αρχεία του φακέλου `frontend` στον web server σας, ώστε να
   είναι προσβάσιμα μέσω του LAMS.

2. Βεβαιωθείτε ότι το `db.php` (από το backend) είναι διαθέσιμο, καθώς το
   `monitor.php` το χρησιμοποιεί για τη σύνδεση με τη βάση δεδομένων.

3. Δημιουργήστε τον πίνακα `clima_grades` στη βάση δεδομένων σας:

   ```sql
   CREATE TABLE clima_grades (
       user_id  INT UNSIGNED NOT NULL PRIMARY KEY,
       username VARCHAR(255) NOT NULL,
       score    INT NOT NULL,
       updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
       UNIQUE KEY (user_id)
   );
   ```

## Χρήση

### Δραστηριότητα φοιτητή (`clima.php`)

Το `clima.php` ελέγχει πρώτα το flag ασφαλείας `LTI_AUTHORIZED`. Αν δεν έχει
οριστεί (δηλαδή ο χρήστης δεν ήρθε μέσω LAMS), επιστρέφει `403 Απαγόρευση
Πρόσβασης`.

Αν η πρόσβαση επιτραπεί, ο φοιτητής μπορεί:

- Να επιλέξει **κλιματικό σενάριο / μοντέλο**:
  - `A1B` — Ισορροπημένο σενάριο IPCC
  - `A2` — Υψηλές εκπομπές (απαισιόδοξο)
  - `B2` — Χαμηλές εκπομπές (οικολογικό)
  - `RegCM_A1B` — Περιφερειακό μοντέλο Ελλάδας
- Να επιλέξει το **έτος πρόβλεψης** (2000–2100) με το ρυθμιστικό.
- Να πατήσει **«Προσομοίωση»** για να δει το διάγραμμα θερμοκρασίας (°C) και
  υγρασίας (%) με κινούμενη απεικόνιση.

**Υπολογισμός προόδου:** Κάθε φορά που ο φοιτητής δοκιμάζει ένα νέο σενάριο,
η πρόοδος αυξάνεται κατά 25% (μέγιστο 100%). Η πρόοδος αποστέλλεται αυτόματα
στο `save_grade.php` του backend (25%, 50%, 75% ή 100%). Όταν ο φοιτητής
ολοκληρώσει και τα 4 σενάρια (100%), εμφανίζεται μήνυμα συγχαρητηρίων.

### Πίνακας ελέγχου εκπαιδευτικού (`monitor.php`)

Το `monitor.php` διαβάζει απευθείας από τη βάση δεδομένων και εμφανίζει:

- **Στατιστικά:**
  - Σύνολο φοιτητών που έχουν καταγραφεί
  - Αριθμός φοιτητών που ολοκλήρωσαν (100%) και ποσοστό ολοκλήρωσης
- **Πίνακα φοιτητών** με στήλες:
  - ID
  - Ονοματεπώνυμο
  - Πρόοδος (%)
  - Κατάσταση (Μόλις ξεκίνησε / Σε εξέλιξη / Ολοκληρώθηκε)
  - Τελευταία δραστηριότητα (ημερομηνία & ώρα, ζώνη Ευρώπης/Αθήνας)

Η σελίδα **ανανεώνεται αυτόματα κάθε 5 δευτερόλεπτα** για να εμφανίζει
ενημερωμένα δεδομένα.

## Σημειώσεις ασφαλείας

- Το `clima.php` επιτρέπει την πρόσβαση μόνο όταν έχει οριστεί το flag
  `LTI_AUTHORIZED` (δηλαδή μετά από επιτυχή πιστοποίηση LTI από το backend).
- Όλα τα δεδομένα χρήστη που εμφανίζονται στη σελίδα περνούν από
  `htmlspecialchars` για την αποφυγή XSS.
- Οι βαθμοί περιορίζονται στο εύρος `0–100` πριν εμφανιστούν.
