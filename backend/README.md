# LAMS Clima — Backend

PHP backend για τη μαθησιακή δραστηριότητα **LAMS Clima**. Αναλαμβάνει την
πιστοποίηση LTI (ώστε η δραστηριότητα να εκκινείται μόνο μέσα από το LAMS) και
την αποθήκευση των βαθμών των μαθητών σε βάση δεδομένων MySQL.

## Επισκόπηση

Το backend αποτελείται από ένα μικρό σύνολο σεναρίων PHP που:

1. **Πιστοποιούν** τα εισερχόμενα αιτήματα μέσω επαλήθευσης υπογραφής
   LTI / OAuth 1.0, ώστε η δραστηριότητα να είναι προσβάσιμη μόνο μέσω LAMS.
2. **Εξυπηρετούν** την ίδια τη δραστηριότητα (μέσω του `clima.php`) αφού
   εξουσιοδοτηθεί το αίτημα.
3. **Αποθηκεύουν** τους βαθμούς των μαθητών σε βάση δεδομένων MySQL
   χρησιμοποιώντας prepared statements.

## Δομή του Έργου

```
backend/
├── db.php          # Σύνδεση με τη βάση δεδομένων (PDO / MySQL)
├── index.php       # Σημείο εισόδου LTI — επαληθεύει το αίτημα και φορτώνει το clima.php
└── save_grade.php  # Endpoint JSON που αποθηκεύει/ενημερώνει τον βαθμό ενός μαθητή
```

## Απαιτήσεις

- PHP 8.1+ (με επέκταση PDO MySQL)
- MySQL / MariaDB
- Ένας web server (Apache, Nginx κ.λπ.) ρυθμισμένος να εξυπηρετεί τον φάκελο `backend`

## Εγκατάσταση

1. Κλωνοποιήστε το repository και δείξτε το document root του web server σας
   (ή ένα virtual host) στον φάκελο `backend`.

2. Διαμορφώστε τη σύνδεση με τη βάση δεδομένων στο `db.php`:

   ```php
   $host     = 'your_db_host';
   $dbname   = 'your_db_name';
   $username = 'your_db_user';
   $password = 'your_db_password';
   ```

3. Δημιουργήστε τον πίνακα `clima_grades` στη βάση δεδομένων σας:

   ```sql
   CREATE TABLE clima_grades (
       user_id  INT UNSIGNED NOT NULL PRIMARY KEY,
       UNIQUE KEY (user_id)
   );
   ```

4. Βεβαιωθείτε ότι το Consumer Key και το Shared Secret στο `index.php`
   ταιριάζουν με τις τιμές που έχουν ρυθμιστεί στην εγκατάσταση LAMS:

   ```php
   $expected_key  = 'lams_key123';
   $shared_secret = 'uth21337';
   ```

## Χρήση

### Εκκίνηση LTI (`index.php`)

Το `index.php` είναι το σημείο εισόδου LTI. Δέχεται μόνο αιτήματα `POST` και
πραγματοποιεί τους εξής ελέγχους:

- Η μέθοδος του αιτήματος πρέπει να είναι `POST` (διαφορετικά επιστρέφει `401`).
- Το `oauth_consumer_key` πρέπει να ταιριάζει με το αναμενόμενο key.
- Η υπογραφή OAuth πρέπει να είναι έγκυρη (HMAC-SHA1 πάνω στις παραμέτρους
  του αιτήματος).

Αν όλοι οι έλεγχοι επιτύχουν, ορίζεται το flag `LTI_AUTHORIZED` και φορτώνεται
το `clima.php`, το οποίο εμφανίζει τη δραστηριότητα.

### Αποθήκευση βαθμών (`save_grade.php`)

Το `save_grade.php` είναι ένα endpoint JSON που δέχεται ένα αίτημα `POST` με
τα εξής parameters:

| Parameter   | Type   | Description                          |
|-------------|--------|--------------------------------------|
| `user_id`  | ακέραιος | Το ID του μαθητή                    |
| `user_name`| string  | Το username του μαθητή               |
| `score`    | ακέραιος | Ο βαθμός 							  |

Χρησιμοποιεί prepared statement με `ON DUPLICATE KEY UPDATE`, οπότε αν ο
μαθητής έχει ήδη εγγραφή, ο βαθμός ενημερώνεται μόνο όταν ο νέος βαθμός είναι
μεγαλύτερος ή ίσος με τον υπάρχοντα.

**Παράδειγμα αιτήματος:**

```bash
curl -X POST https://your-domain/backend/save_grade.php \
  -d "user_id=42" \
  -d "user_name=jdoe" \
  -d "score=85"
```

**Παράδειγμα απάντησης:**

```json
{
  "status": "success",
  }
}
```


## Απαντήσεις API

| HTTP Status | Σημασία                                        |
|-------------|------------------------------------------------||
| `200`       | Ο βαθμός αποθηκεύτηκε/ενημερώθηκε επιτυχώς     |
| `400`       | Μη έγκυρα ή ελλιπή δεδομένα                    |
| `401`       | Αποτυχία πιστοποίησης LTI (index.php)          |
| `405`       | Μη επιτρεπτή μέθοδος (μόνο `POST`)             |
| `500`       | Σφάλμα βάσης δεδομένων (καταγράφεται, δεν εκτίθεται) |


## Σημειώσεις ασφαλείας

- Όλη η πρόσβαση στη βάση δεδομένων γίνεται με **PDO prepared statements**
  για την αποφυγή SQL injection.
- Το `score` περιορίζεται στο εύρος `0–100` πριν αποθηκευτεί.
- Τα σφάλματα βάσης δεδομένων καταγράφονται στο server log και **δεν**
  εκτίθενται στον χρήστη.
- Η δραστηριότητα μπορεί να εκκινηθεί μόνο μέσω LAMS χάρη στην επαλήθευση
  υπογραφής OAuth.
